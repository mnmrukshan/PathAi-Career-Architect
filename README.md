# PathAI - Career Architect 🧠🚀

PathAI is an AI-powered career growth and path-finding platform that turns professional guesswork into strategic execution. 

## 🔋 Core Capabilities
- **Roadmap Generation**: Custom 12-week plans to bridge skill gaps.
- **AI Interviewer**: Interactive mock interviews with real-time feedback.
- **Resume Optimization**: Deep PDF analysis and strategic refinement.
- **Career Cockpit**: Data-driven progress tracking and analytics.

## 🛠 Tech Stack
- **Next.js 16**, **Tailwind CSS 4**, **Framer Motion**
- **FastAPI**, **MongoDB**, **Google Gemini AI**
